## The actuarial and data science connection

My actuarial background shapes how I approach technical work:

- define the business decision before choosing a model;
- separate frequency, severity, exposure and uncertainty;
- evaluate errors according to their real-world cost;
- check assumptions, leakage, bias and data limitations;
- translate model output into measured recommendations;
- treat monitoring and communication as part of the model lifecycle.
